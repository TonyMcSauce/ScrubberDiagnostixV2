Welcome to ScrubberDiagnostix
A fault diagnostic reference for the SP750 hydrostatic drive system powering the scrubber drum at Jwaneng Mine. Select observed symptoms, run the analysis, and get ranked fault causes with specific pressure measurement ports and action steps.
STEP 01
Select one or more observed symptoms from the left panel — combine them for multi-fault analysis.
STEP 02
Press RUN DIAGNOSTIX. The system cross-references all selected symptoms and ranks likely faults.
STEP 03
Review the fault tree. Each fault lists measurement ports, expected readings, and step-by-step actions.
SYSTEM MAP
The diagram at the top highlights affected components in amber (caution) or red (critical) during diagnosis.
This tool is a diagnostic aid only. Always follow Debswana safe work procedures.
